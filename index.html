Before we begin

Kin is a portrait that listens to the body. It needs your camera and your consent. No video, audio, or measurements are uploaded.

Your camera, on this device

SmartSpectra estimates pulse, breathing, and — only if you opt in — visible facial expression. The measurement engine runs locally inside the SDK.

The portrait responds

A warm light follows your measured pulse, the traces show your breathing and pulse, and — only if you opt in — the face mirrors visible expression. When a signal is missing, the portrait stays still.

No body data saved

Kin writes no video, audio, images, measurements, history, or API key to disk. SmartSpectra may keep a technical device-key/model cache and diagnostic logs under Windows app data; they contain no camera frames, audio, or readings. The Kin session itself is non-persistent.

What leaves this device

Presage requests: authentication, usage verification, and encrypted model downloads. They can include your API key and session usage metadata, but never the camera preview, audio, or your measured values.

Telemetry is off. No session summaries or readiness reports are sent. Kin has no account, analytics, or cloud storage.

The full data note
  • Storage: Kin itself stores no recordings, images, measurements, history, or API key. SmartSpectra may keep a technical device-key/model cache and diagnostic logs under Windows app data; these contain no camera frames, audio, or measured values. Chromium may keep ordinary app cache files; the Kin session is non-persistent.
  • Sharing: none by Kin. The native SDK contacts Presage for authentication, usage verification, and encrypted models. Those requests do not carry preview frames, audio, or measured values.
  • Retention: session state lives in memory and disappears on End or close. Technical SDK/app files may remain until you delete them; they contain no body data.
  • Deletion: use End session or close Kin to clear session state. On Windows, the technical files are under %APPDATA%\\Kin, %LOCALAPPDATA%\\Presage\\Physiology, %LOCALAPPDATA%\\SmartSpectraSDK, and %LOCALAPPDATA%\\Temp\\SmartSpectra*.log.*. Delete them to remove those caches and logs. There is no Kin account or cloud copy.
  • SDK telemetry: disabled. Kin sets enableTelemetry: false.
  • AI: none. Kin does not use LLM Insights or send data to an AI service.

You can pause the camera or end the session at any time. Closing the app clears the in-memory key and all session state.

One key, held in memory

Wake the portrait

Paste your SmartSpectra API key. It is used once to authorize the session, then kept only in memory.

The camera opens next. The portrait and your self-view appear together in the studio. Position your head, shoulders, and upper chest in the self-view. The first signals can take up to a minute; keep still and stay in frame. Press F if you want the portrait in its own window.

Kin uses this key only for Presage authentication and usage verification. It is never written to disk, logged, or included in the repository. Closing the app forgets it.

No key yet? Create one at the Presage portal.

Privacy & data

What Kin keeps

Kin is built so the intimate part — your face and body — never leaves the room.

In memory, only while you listen

  • Camera frames, shown only in the local self-view and processed in memory by the native SmartSpectra SDK. No frame is recorded or written.
  • Derived animation values: pulse envelope, chest phase, expression targets.
  • Your API key, held by the SDK for the session.

Never

  • Video or audio recordings. Kin never opens a microphone or captures audio.
  • Uploads of frames, audio, or measurements.
  • Analytics, accounts, or cloud storage.
  • Facial landmarks — Kin does not request them.
  • Session summaries or readiness reports.

Presage network requests

Presage authenticates your API key, verifies usage, and provides encrypted model artifacts. SmartSpectra's measurement engine runs on this device. Telemetry is disabled, so no session summary or device-readiness report is sent; required usage accounting still runs. These requests can be correlated with your Presage account and can include session usage metadata, but not preview frames, audio, or measured values. Kin adds no analytics or uploads of its own.

Retention & deletion

There is no database, no recording, and no persistent Electron session. End session or close Kin to clear the key and every derived value from memory. SmartSpectra may leave a technical device-key/model cache and diagnostic logs under Windows app data, and Chromium may keep ordinary app cache files. None contain camera frames, audio, or measured values; the README lists the folders you can delete.

AI

Kin does not use LLM Insights and does not send any data to an AI service.

Verify it in the source: the renderer runs under connect-src 'none', the Electron partition is non-persistent, facial landmarks are not requested, and the SDK is created with enableTelemetry: false.

The full note is also in the repository README and the DEV submission.
